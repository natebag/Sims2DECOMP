### Reference Counting Pattern
This is a standard COM-style reference counting implementation:
1. Each Release() decrements the counter
2. When counter reaches 0, the object is deleted
3. A virtual destructor is called with a specific flag (3)
4. The flag likely distinguishes between "complete destruction" and "partial cleanup"
